# Brug Open Homey App v1.0.2

- Landelijke zoekfunctie uitgebreid voor alle beweegbare bruggen die via Rijkswaterstaat FIS beschikbaar zijn.
- Zoekt op brugnaam, plaats, doorvaartopening en ISRS-objectnaam.
- Gangbare publieksnamen kunnen via de officiële PDOK/Kadaster Location API naar de juiste beweegbare FIS-brug worden gekoppeld.
- Resultaten worden samengevoegd op dezelfde FIS/ISRS-brug.
- Slimmere herkenning van samengestelde namen en Noord/Zuid/Oost/West.
